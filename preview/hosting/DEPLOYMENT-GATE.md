# 3.0.7.2 — approval-only hosting plan
Select self-hosting on existing hardware, using free open-source WireGuard and a private HTTPS reverse proxy (Caddy with internal CA). No new cloud resources or subscription. Hardware, electricity, connectivity and an accessible VPN endpoint are prerequisites, not verified. Tailscale Personal is non-commercial only, so do not assume eligibility for Resident Labs monetization development. No account creation or deployment. On a CGNAT connection, direct inbound WireGuard may not work; stop until a compliant zero-cost reachable endpoint is confirmed. Do not open public application ports.
Use a dedicated Linux host or isolated Linux VM with systemd cgroup IP filtering support, not the production host. Install only Bun and the synthetic entry plus independent-mocks.ts, never dotenv files or full app. Use the service template with a dedicated unprivileged user. Proxy binds only to the VPN interface; backend remains loopback. Preserve exact HTTPS Host and Origin and Basic Authorization; never log Authorization. Proxy must reject other hosts, no public listener, no upstream internet access required for private CA. Generate a unique random password and store in root-owned mode 0600 environment file. Set RESIDENT_PREVIEW_ORIGIN to exact HTTPS origin. Enroll only approved devices, install and explicitly trust dedicated private CA on test devices; never bypass certificate warnings. Protect CA key separately and remove trust on rollback. Do not modify production DNS.
StateDirectory is synthetic only, private mode 0700. Backup while stopped; never mount production data. Confirm cgroup IPAddressDeny actually enforced on selected host, perform same-service-context negative outbound IPv4/IPv6/DNS probes using controlled destinations, verify proxy loopback works and unapproved peers cannot reach HTTPS. Stop if enforcement unavailable. Browser request assertions are not infrastructure isolation.
Actual iPhone Safari checklist: connect VPN, confirm valid HTTPS and certificate trust, verify wrong password rejected, authenticate, submit checkout, verify simulated confirmation, refresh and restart service then verify order persists, test portrait/landscape, disconnect VPN and verify inaccessible. Repeat on Mac. Verify forbidden endpoints and origin rejection using controlled HTTP client, not real wallet. Record OS/browser versions and statuses without secrets.
Rollback: disable dedicated proxy listener, stop dedicated service, revoke test VPN peer keys, remove preview CA trust and dedicated credentials, retain or remove only synthetic storage with approval. No shared VPN or production settings changes.
Build warnings: keep thresholds and diagnostics visible; inspect dependency config parsing and circular inherits/util and stream-browserify/readable-stream chunks before changing bundling. Measure baseline and compare candidate changes with complete unit and browser regression suite. No speculative dependency changes in this hosting-only revision.
Approval gate: confirm existing host, VPN reachability, no incremental charges, CA trust choice, isolation enforcement and successful CI before any installation or deployment.
